# NPass (legacy)

Offline password manager, published as N-Password Manager.

This repository holds the original native Android app (Java). It is archived and no longer maintained.
The app is now developed in Flutter at [netersoft/n-pass](https://github.com/netersoft/n-pass).
The new app keeps the same application id, so it ships on the [Play Store](https://play.google.com/store/apps/details?id=com.neteru.n_pass) as an update of this one.

## Project

- Application id: `com.neteru.n_pass`
- Version in this repository: 1.1.3
- Android Studio project (Gradle), `minSdkVersion` 16

The project targets the Android SDK and Gradle versions of its time and is not expected to build as is with current tools.
